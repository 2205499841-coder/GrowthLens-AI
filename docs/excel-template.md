# GrowthLens Excel 数据接入说明

当前支持 `.xlsx` 文件。系统会遍历工作表并选择最符合分析条件的数据区域。

## 用户级明细数据

完整用户级分析使用以下字段，其中漏斗过程字段可以缺失：

| 字段 | 含义 | 可用性 |
| --- | --- | --- |
| `user_id` | 用户唯一标识 | 核心字段 |
| `channel` | 首次获客渠道 | 核心字段 |
| `register_time` | 注册时间 | 核心字段 |
| `view_time` | 首次深度浏览时间 | 可选字段 |
| `lead_time` | 首次留资时间 | 可选字段 |
| `appointment_time` | 首次预约时间 | 可选字段 |
| `visit_time` | 实际到店时间 | 可选字段 |
| `pay_time` | 首次有效支付时间 | 可选字段 |
| `order_amount` | 首次有效订单金额 | 核心字段 |

字段名允许存在前后空格，解析时会自动去除。未完成的阶段可以留空。

## 聚合经营指标数据

包含品类、渠道、用户规模、转化率、同比、环比或金额等字段的聚合报表，
当前可完成 `aggregate_metrics` 类型识别。本阶段暂不生成完整聚合经营分析。

## 当前限制

- 文件大小不超过 10 MB；
- 候选数据工作表必须至少包含一行数据；
- 无法计算的指标返回 `null` 或 unavailable 状态，不使用 `0` 代替；
- 上传文件只在请求过程中读取，不保存到数据库或本地项目目录。
