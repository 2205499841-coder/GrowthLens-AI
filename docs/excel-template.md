# GrowthLens Excel 数据模板

第一阶段只读取 `.xlsx` 文件的第一个工作表。

## 必填字段

| 字段 | 含义 |
| --- | --- |
| `user_id` | 用户唯一标识 |
| `channel` | 首次获客渠道 |
| `register_time` | 注册时间 |
| `view_time` | 首次深度浏览时间 |
| `lead_time` | 首次留资时间 |
| `appointment_time` | 首次预约时间 |
| `visit_time` | 实际到店时间 |
| `pay_time` | 首次有效支付时间 |
| `order_amount` | 首次有效订单金额 |

字段名允许存在前后空格，解析时会自动去除。未完成的阶段可以留空。

## 当前限制

- 文件大小不超过 10 MB；
- 第一个工作表必须至少包含一行数据；
- 必填字段必须全部存在；
- 上传文件只在请求过程中读取，不保存到数据库或本地项目目录。
