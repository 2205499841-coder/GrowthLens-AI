# GrowthLens 增长分析口径

## 分析粒度

- 一行代表一个小程序用户；
- `user_id` 是唯一业务键；
- 所有时间均按业务本地时间解释；
- 上传文件只在单次请求内处理，不落库。

## 清洗规则

1. 空用户 ID 的记录删除；
2. 重复用户优先保留必填字段最完整的记录，完整度相同时保留先出现的记录；
3. 渠道去除前后空格，空渠道归类为“未知”；
4. 时间统一转换为日期时间类型；
5. 无法解析、晚于当前时间一天以上、跳过前置步骤或早于前序步骤的时间视为异常，并从异常步骤起停止漏斗计数；
6. 空金额按 `0` 处理，非法或负金额修正为 `0`；
7. 没有有效支付时间却存在正金额时，将金额修正为 `0`。

`anomaly_count` 表示至少命中一项质量规则的原始行数，各规则明细见
`issue_counts`。同一行可命中多项规则，因此明细之和不一定等于异常行数。

`data_completeness` 只评估业务必填信息，不把正常漏斗流失当成数据缺失：

- 所有有效用户：用户 ID、渠道、注册时间；
- 成交用户额外检查：订单金额是否大于 `0`。

## 指标口径

基础用户数按完整的逐级路径统计，保证漏斗人数单调递减：

1. 注册用户数：存在有效注册时间；
2. 浏览用户数：已注册且存在有效浏览时间；
3. 留资用户数：已浏览且存在有效留资时间；
4. 预约用户数：已留资且存在有效预约时间；
5. 到店用户数：已预约且存在有效到店时间；
6. 成交用户数：已到店且存在有效支付时间。

转化率均为相邻环节转化：

- 浏览率 = 浏览用户数 / 注册用户数；
- 留资率 = 留资用户数 / 浏览用户数；
- 预约率 = 预约用户数 / 留资用户数；
- 到店率 = 到店用户数 / 预约用户数；
- 成交率 = 成交用户数 / 到店用户数。

收入指标：

- GMV = 成交用户有效订单金额之和；
- 客单价 = GMV / 成交用户数。

渠道分析使用相同口径分别计算，保证 Dashboard 总览与渠道视图可以复用同一结构。
